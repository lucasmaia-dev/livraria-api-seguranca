# Livraria API - Semana 10

API de Livros e Autores com BCrypt, JWT, RBAC e documentação OpenAPI 3.0.3 com Swagger UI.

O código e o guia completo estão em [livraria-api-node-main](<livraria-api-seguranca-pronto (1)/livraria-api-node-main/README.md>).

## Iniciar

Requer Node.js 22.19 ou superior (recomendado: Node.js 24).

```bash
cd "livraria-api-seguranca-pronto (1)/livraria-api-node-main"
npm ci
npm start
```

- Swagger UI: http://localhost:3000/docs
- OpenAPI JSON: http://localhost:3000/docs/api.json
- Testes: `npm test` na pasta da API.

Use o login no Swagger, copie o token retornado e cole em **Authorize**. O README da API contém credenciais locais de demonstração, matriz de permissões e o roteiro completo de avaliação.

O GitHub hospeda o código da entrega; os endereços localhost funcionam com a API executando no computador.
